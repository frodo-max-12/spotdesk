The human contract

  • The agent works 24/7; the Drafts folder always holds the current answer — re-priced quotes replace their stale drafts.
  • Human input is high-value, low-bit: Send / edit-then-Send / discard, one Release per RFQ batch, one Close per finished deal.
  • Auto-send exists but is opt-in per action type, only in automatic mode, and never for a quote the confidence gate holds.

The compounding loop

  • Capture — every quote stores its decision-time snapshot (all competing lots, trust, market median).
  • Apply — the quote itself is a prediction (we_quoted_usd).
  • Feedback — desk close won|lost|no_response writes the label and fires the trust update and appends the clearing price. Silence is censored, never counted as a loss.
  • Distill — weekly report of KPIs + surprises, drafted for the operators; surprises become playbook edits.
